# WinterControl

Плагин для Paper 1.21.4. Требуется Java 21.

## Возможности

- Русскоязычное меню.
- Ручная и автоматическая остановка тиков.
- Настройка интервала и длительности остановки.
- Постепенное замерзание поверхностной воды.
- Разовое покрытие снегом.
- Долгий снегопад с накоплением.
- Таяние снега и обычного льда возле источников тепла.
- Замена естественно появляющихся скелетов зимогорами.
- Снежные лисы при естественном появлении.
- Урон животным выше настраиваемой границы Y.

## Команды

- `/winter` — открыть меню.
- `/winter freeze` — остановить тики.
- `/winter unfreeze` — возобновить тики.

Право доступа: `wintercontrol.admin`.
По умолчанию доступно операторам.

## Автоматическая сборка

После отправки изменений открой вкладку Actions.
Выбери завершившуюся сборку и скачай артефакт
WinterControl-Paper-1.21.4.

Распакуй архив и перенеси WinterControl.jar
в папку plugins сервера. Перезапусти сервер.

## Ограничения первой версии

- Обрабатываются только загруженные чанки обычных миров.
- Снегопад отображается частицами; снег на земле — настоящими блоками.
- Тепло проходит через стены.
- Выключение зимы не откатывает изменения карты.
- Приручённые животные тоже могут получать урон от холода.
- Интеграция с защитой территорий не реализована.

Перед использованием на основном сервере проверь плагин на копии мира.
